# VARNIX APOCALYPSE LITE

افزونه فارسی بقا در آخرالزمان برای Minecraft Bedrock؛ با حفظ ظاهر بلوکی ماینکرفت و تمرکز بر عملکرد مناسب موبایل.

## قابلیت‌های پیاده‌سازی‌شده در این مرحله
- فعال‌سازی خودکار اسکریپت هنگام ورود بازیکن؛ نیازی به اجرای دستور راه‌اندازی نیست.
- آلودگی در اثر ضربه زامبی‌های افزونه؛ شمارش معکوس ۵ دقیقه‌ای و درمان با مصرف پادزهر.
- سنگ معدن اورانیوم قابل استخراج (فعلاً با قرار دادن بلوک یا از طریق غنیمت جعبه‌ها قابل دسترسی است؛ تولید طبیعی در جهان هنوز اضافه نشده)؛ اورانیوم برای پادزهر، سلول انرژی و مهمات اورانیومی با ۵۰٪ آسیب بیشتر استفاده می‌شود.
- ژنراتور قابل ساخت و روشن/خاموش‌کردن با زغال (۵ دقیقه)، گالن سوخت (۱۰ دقیقه) یا سلول اورانیومی (۲۰ دقیقه)؛ برق موقت رایانه و دوربین را در محدوده ۱۶ بلوک تأمین می‌کند.
- چهار سلاح، خشاب و بارگذاری مجدد با جعبه مهمات، گوشی، بی‌سیم، کلید خودرو، کنسول رایانه و دوربین.
- دشمنان آلوده، باس، خودروی ساده، پناهگاه، بیمارستان و مأموریت‌های داستانی قبلی.

## کنترل‌ها
هیچ دستور راه‌اندازی لازم نیست. برای راهنمای داخل بازی می‌توانی از /function varnix_help استفاده کنی. دستورات مأموریت‌ها و ساخت سازه‌ها همچنان اختیاری‌اند.

## سازگاری و محدودیت آزمون
حداقل نسخه هدف 1.21.51 است و 1.21.94 باید جداگانه در بازی آزموده شود. ساخت موفق GitHub Actions به‌تنهایی اجرای واقعی Add-on را تضمین نمی‌کند. تولید طبیعی سنگ معدن اورانیوم در جهان، مدل‌ها و تکسچرهای اختصاصی و تست runtime و چندنفره همچنان نیازمند بررسی در Minecraft هستند.
