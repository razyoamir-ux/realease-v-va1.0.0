# VARNIX APOCALYPSE LITE

Add-on فارسی Minecraft Bedrock با ظاهر وفادار به ماینکرفت و تمرکز بر کیفیت و عملکرد.

## وضعیت توسعه
این commit اسکلت قابل بسته‌بندی Behavior Pack و Resource Pack را ایجاد می‌کند. قابلیت‌های کامل مانند سلاح شلیک‌کننده، خودرو، رایانه تعاملی، دوربین نظارتی، داستان چندنفره و مدل‌های نهایی هنوز پیاده‌سازی و آزمایش نشده‌اند؛ این نسخه انتشار نهایی نیست.

## هدف سازگاری
- حداقل هدف: Bedrock 1.21.51
- نسخه آزمون مهم: Bedrock 1.21.94
- نسخه‌های بالاتر فقط پس از آزمون هر نسخه تأیید می‌شوند.
- پایه پروژه بدون وابستگی به Experimental APIs است.

## ساختار
- VARNIX_BP/: رفتارها و داده‌های بازی
- VARNIX_RP/: منابع و ترجمه فارسی
- .github/workflows/package-addon.yml: بسته‌بندی خودکار mcaddon

## حالت‌ها
1. داستان گروهی: مأموریت‌ها و پیشروی مشترک.
2. بقای آزاد: بدون اجبار به دنبال‌کردن داستان.

## کیفیت
هیچ قابلیت ناتمام یا آزمایش‌نشده به‌عنوان بدون باگ معرفی نمی‌شود. سازگاری نسخه‌ها و عملکرد چندنفره باید روی دستگاه واقعی آزمایش شوند.
