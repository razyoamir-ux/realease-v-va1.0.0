# VARNIX APOCALYPSE LITE

افزونه بقا و آخرالزمان فارسی برای Minecraft Bedrock؛ نسخه توسعه 0.4.0.

## تجهیزات افزوده‌شده در شاخه 0.4.0
- ۱۰ آیتم جدید: ماسک ضدآلودگی، جلیقه تاکتیکی، کیف کمک‌های اولیه، چراغ‌قوه، کوله‌پشتی، جیره غذایی، فیلتر آب، GPS، لپ‌تاپ عملیاتی و دوربین دیجیتال.
- برای هرکدام فایل تعریف آیتم و رسپی ساخت اضافه شده است.
- تکسچرهای پیکسلی اختصاصی برای ۱۰ وسیله جدید و چهار سلاح اصلی به Resource Pack افزوده شده‌اند.
- استفاده از کیف کمک‌های اولیه، ماسک، جلیقه، چراغ‌قوه، فیلتر آب، GPS، لپ‌تاپ و دوربین به رویدادهای داخل بازی متصل شده است.
- قابلیت‌های قبلی حفظ شده‌اند: زامبی‌ها، آلودگی پنج‌دقیقه‌ای، پادزهر، اورانیوم، ژنراتور، رایانه، دوربین مداربسته، مأموریت‌ها و خودرو.

## کنترل و شروع
بعد از فعال‌سازی Behavior Pack و Resource Pack در تنظیمات جهان، سیستم اسکریپت هنگام ورود بازیکن خودکار اجرا می‌شود. نیازی به تایپ دستور برای شروع نیست. راهنمای ساخت داخل بازی از آیتم «راهنمای رسپی» در دسترس است.

## نکته‌های مهم
- تکسچرهای جدید در این نسخه آیکون‌های پیکسلی اختصاصی آیتم‌ها هستند؛ مدل سه‌بعدی و انیمیشن اختصاصی برای تمام تجهیزات هنوز کامل نشده است.
- کوله‌پشتی فعلاً آیتم کاربردی/نمایشی با پیام راهنماست و ظرفیت Inventory را افزایش نمی‌دهد.
- فعال‌شدن افکت‌ها و سازگاری نهایی باید داخل Minecraft Bedrock 1.21.51 و 1.21.94 آزمایش شود؛ موفقیت بسته‌بندی به معنی تست runtime نیست.
- نمایش حروف فارسی به موتور رابط Minecraft وابسته است؛ این نسخه هنوز راه‌حل قطعی برای اتصال حروف در تمام صفحه‌ها ارائه نمی‌کند.
