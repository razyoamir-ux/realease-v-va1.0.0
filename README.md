# VARNIX APOCALYPSE LITE

افزونه فارسی بقا در آخرالزمان برای Minecraft Bedrock؛ با حفظ ظاهر بلوکی ماینکرفت و تمرکز بر عملکرد مناسب موبایل.

## هدف سازگاری
- حداقل نسخه هدف: Bedrock 1.21.51
- نسخه مهم برای آزمون: 1.21.94
- نسخه‌های بالاتر تا زمان آزمون جداگانه تضمین نمی‌شوند.
- چندنفره از طریق قابلیت‌های خود Minecraft/Realm/سرور انجام می‌شود؛ تعداد بازیکنان به میزبان و تنظیمات جهان وابسته است.

## پیاده‌سازی فعلی در مخزن
- Behavior Pack و Resource Pack با manifest و بسته‌بندی خودکار.
- Script API برای شلیک چهار سلاح، آسیب هدف، خشاب و بارگذاری مجدد با جعبه مهمات.
- گوشی درون‌بازی با راهنمای دستورات، بی‌سیم داستانی و کلید فراخوانی خودرو.
- کنسول رایانه با سرنخ داستانی، کنسول دوربین با شمارش آلوده‌های نزدیک و جعبه تدارکات با جدول غنیمت.
- چهار دشمن: آلوده معمولی، سریع، سنگین و باس جهش‌یافته آلفا با ۲۵۰ سلامتی.
- خودروی دو سرنشین با مدل بلوکی ساده؛ کنترل رانندگی باید در بازی واقعی آزموده شود.
- بانداژ، منور، دیلم، جعبه مهمات، گوشی، بی‌سیم، کلید خودرو و دستور کیت بازمانده.
- پناهگاه و بیمارستان متروکه قابل ساخت با دستور، مأموریت‌های آزمایشگاه و بیمارستان و باس آلفا.
- ترجمه فارسی آیتم‌ها، بلوک‌ها و دشمن‌ها.

## نکات مهم
- گوشی و دوربین‌ها فقط در محیط Minecraft شبیه‌سازی می‌شوند و به سخت‌افزار واقعی موبایل دسترسی ندارند.
- این مخزن هنوز نسخه نهایی نیست. مدل‌ها/تکسچرهای اختصاصی نهایی، نقشه کامل شهر و بیمارستان با جزئیات بیشتر، خودروهای بیشتر، مراحل باس چندمرحله‌ای، سوخت و تعمیر خودرو، سیستم دوربین زنده و تست چندنفره و آزمون واقعی روی Bedrock 1.21.51 و 1.21.94 باقی مانده‌اند.
- اجرای موفق GitHub Actions فقط بسته‌بندی فایل‌ها را ثابت می‌کند، نه اجرای بی‌خطای Add-on داخل بازی.
